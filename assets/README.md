# Paper assets and link badges

`overview.pdf` is the original overview figure from *HyWe: Unifying Search
and Operation for Real-World Hybrid Web Tasks* (`fig_overview_v13.pdf`).
`overview.png` is a 2480 × 1368 rendering of that PDF for README display.
The figure's contents are preserved.

The SVG link badges in `badges/` were generated with
[Shields.io](https://shields.io/) using GitHub and Hugging Face icons.
They are stored locally so the resource buttons do not require a live badge
generation service when the README is viewed.
